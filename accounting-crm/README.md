# AGR Accounting CRM

CRM contable separado del CRM principal de AGR Solutions LLC.

Primera fase:
- Empresas
- Trabajos
- Sales & Use Tax / OS-114
- Gastos y posible Use Tax
- Declaraciones
- Portal simplificado para clientes

La clasificación tributaria es una ayuda administrativa y requiere revisión antes de presentar a Connecticut DRS.

Esta versión usa localStorage y datos de prueba. No usar datos sensibles reales hasta añadir autenticación y base de datos segura.

# AGR CRM — Prototype v1

Rama de desarrollo separada de la web pública.

## Objetivo
Crear una CRM interna para AGR Solutions LLC enfocada en:
- Clientes
- Casos y trámites
- Estados y próximos pasos
- Pagos y saldos
- Citas
- Notas y checklists (siguiente fase)
- Portal/archivos/contratos (fases posteriores)

## Estado actual
Prototype v1 con interfaz funcional y datos de prueba almacenados en `localStorage`.

**Importante:** no usar datos reales o sensibles todavía. Este prototipo no tiene autenticación ni base de datos segura.
